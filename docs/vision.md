# Vision 

## Project Overview

The goal of this project is to develop a Manufacturing Execution System - (MES).
This application will support production processes, machine monitoring and production order execution.
This project is inspired by semiconductor manufacturing processes used by TSMC.

## Project Goals 

Learning Goals  
- Develop new skills in Java programming language 
- Learn Spring Boot
- Gain experience with PostgreSQL.
- Build a REST API following good software engineering practices. 
- Gain some experience in Angular 

Bussines Goals
- Manage production orders,
- Monitor machines,
- Track wafer batches, 
- Record production history,
- support quality inspection, 


## User Roles

- Admin
Has full, unrestricted accesss to all systems settings, user management and core configurations.
- Production Manager 
Creates orders, monitors manufacturing progress
- Production Operator
Controls/Executes production steps, operates machines, reports issues
- Quality Engineer 
Approve/reject batches
